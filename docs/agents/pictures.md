# Homie Pics

Opens apartment listings in a real headless browser (Playwright) and sends screenshots, so renters abroad can see a place before they sign. Send it any link: Zillow, Apartments.com, or a building's own site. It also reads live advertised prices off building websites when offices are closed.

Part of Homie, a 11-agent Fetch.ai team that's an international student's person in America: Homie, Calls, Negotiator, Papers, Fix, Policy, Pics, Memory, Later, Scout and Vibecheck.
